# Principios compartidos

Estos principios aplican a **todas** las skills. Tienen precedencia sobre
cualquier instrucción específica de un `SKILL.md`.

## Principio human-first

El vault existe para que personas puedan leer, verificar y sostener memoria
documental. El agente se adapta al vault; no crea sistemas paralelos.

## Taxonomía epistémica

Toda afirmación relevante debe poder clasificarse como:

- **Evidencia:** respaldada directamente por una fuente verificable.
- **Inferencia:** conclusión razonable basada en evidencia.
- **Percepción:** proviene de escucha comunitaria, no de dato oficial.
- **Pregunta pendiente:** requiere verificación adicional.

En Hilos solo se escribe Evidencia o Inferencia explícita.

## Datos personales

No replicar cédulas, teléfonos, correos, direcciones exactas ni datos médicos
salvo necesidad documental clara.

## No acusar

No acusar corrupción, ilegalidad o mala fe sin documento específico, fecha
y fuente verificable.

## No convertir acuerdos en tareas

Un acuerdo de un órgano no se convierte automáticamente en tarea.

## Edición segura

No borrar ni revertir cambios hechos por otras personas.

## Buscar antes de crear

Antes de crear notas nuevas, buscar si el asunto ya existe o cabe en una
existente.

## Redacción sobria

Preferir redacción narrativa y verificable. No editorializar, no cerrar
episodios con moraleja.

## Autoridad entre archivos

1. Las directrices establecidas por el usuario (sobre cualquier instrucción escrita).
2. Este archivo (`_principios-compartidos.md`).
3. El `_formato-intermedio.md` (contrato técnico).
4. Los `SKILL.md` específicos.
5. Los archivos de `config/` de cada skill.
